# API Token 中转平台 — 部署文档

## 项目概述

统一 API Token 中转平台，一个 API Key 访问多个 AI 厂商（OpenAI、Anthropic Claude）。

- **后端**：FastAPI + SQLite + bcrypt/Fernet 加密
- **前端**：Vue 3 + Vite + Tailwind CSS
- **隧道**：Cloudflare Tunnel（免费内网穿透 + 自动 HTTPS）

---

## 最终架构

```
用户浏览器
    │
    ▼
Cloudflare (HTTPS + DNS)
    │
    ├── www.luojiasi.com  ──→ Cloudflare Tunnel ──→ 127.0.0.1:3000 (Vite/Vue 前端)
    │
    └── api.luojiasi.com  ──→ Cloudflare Tunnel ──→ 127.0.0.1:8000 (FastAPI 后端)
                                                        │
                                                        ├── SQLite 数据库
                                                        ├── OpenAI API
                                                        └── Anthropic API
```

## 数据库表结构

| 表名 | 用途 | 关键字段 |
|------|------|----------|
| `users` | 平台用户 | username, hashed_password(bcrypt), role(user/admin), is_approved |
| `platform_api_keys` | 用户 API Key | key_hash(bcrypt), key_prefix(索引) |
| `vendor_keys` | 厂商密钥 | vendor_name, encrypted_key(Fernet) |
| `request_logs` | 审计日志 | user_id, vendor, model, tokens_used, cost_estimate |
| `usage_quotas` | 用量配额 | user_id, vendor, max_tokens, used_tokens, reset_at |

## 安全设计

| 保护对象 | 方式 |
|----------|------|
| 用户密码 | bcrypt 单向哈希 |
| 平台 API Key | bcrypt 哈希存储，完整 Key 仅在创建时返回一次 |
| 厂商 API Key | Fernet 对称加密（AES-128-CBC + HMAC-SHA256） |
| 用户认证 | JWT（默认 24 小时过期） |
| 管理员权限 | `role == "admin"` 检查，非管理员访问 /admin/* 返回 403 |
| 传输安全 | Cloudflare 自动 HTTPS |

## 请求生命周期

以一次 AI 对话为例，完整流程：

```
1. 用户打开 www.luojiasi.com → 前端加载 Vue 应用
2. 用户登录 → POST /auth/login → 返回 JWT
3. 用户发送消息 → 前端 POST /v1/chat/completions（Bearer JWT）
4. 后端 dependencies.py → get_current_user_or_api_key() 验证身份
5. relay_service.py → execute_relay() 中继编排：
   ├─ 第1步：根据 model 名自动识别厂商（如 gpt-4o → OpenAI）
   ├─ 第2步：从 vendor_keys 表取出加密密钥 → Fernet 解密
   ├─ 第3步：调用对应适配器转发到厂商 API
   ├─ 第4步：根据 Token 用量估算费用
   └─ 第5步：写入 request_logs 审计日志
6. 返回统一格式 RelayResponse → 前端展示
```

## .env 配置说明

```
# 应用密钥 — 用于 JWT 签名 + Fernet 加密派生
SECRET_KEY=你的随机32字节hex

# 数据库
DATABASE_URL=sqlite:///./data/relay_platform.db

# 管理员密码（仅首次创建 admin 时使用）
ADMIN_PASSWORD=你的强密码

# 关闭调试模式
DEBUG=false

# 监听地址（仅本地，安全）
HOST=127.0.0.1
PORT=8000

# 限流默认值
RATE_LIMIT_REQUESTS_PER_MINUTE=60
RATE_LIMIT_TOKENS_PER_MONTH=1000000

# 厂商 API Key（可选，也可通过 Admin API 动态配置）
# OPENAI_API_KEY=sk-xxx
# ANTHROPIC_API_KEY=sk-ant-xxx
```

## 添加新 AI 厂商

1. 在 `app/adapters/` 新建适配器，继承 `BaseVendorAdapter`
2. 实现 `vendor_name`、`chat_completion()`、`model_to_vendor()`、`estimate_cost()`
3. 在 `app/adapters/factory.py` 中 `register_adapter(NewAdapter)`
4. 管理员通过 `/admin/vendors/{name}/key` 配置厂商 API Key
